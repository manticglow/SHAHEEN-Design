# شاهين ديزاين: الموقع + لوحة التحكم + بوت الواتساب

مشروع واحد على GitHub، يشتغل على **Vercel** ويخزن في **Supabase**:

| الرابط | وش هو |
|---|---|
| `/` | الموقع (المتجر) |
| `/salla`، `/wallet`، `/company` … | صفحة لكل منتج بعنوانه ووصفه وصورة معاينته، عشان قوقل والواتساب |
| `/book` | حجز استشارة مجانية ١٥ دقيقة |
| `/sitemap.xml` و `/robots.txt` | خريطة الموقع لقوقل (تنبني تلقائيًا من المنتجات) |
| `/admin` | لوحة التحكم: تعدل منها الأعمال والخدمات والصور والنصوص والإعدادات |
| `/webhook` | بوت الواتساب (يربط مع Meta) |
| `/leads` | صفحة الطلبات |

```
lib/site.html           الموقع نفسه (التصميم والمنتجات والأسعار)
og/                     صور المعاينة لما ينرسل الرابط (وحدة لكل منتج)
images/ …               الصور والأيقونات
api/index.js            الخادم (دالة Vercel وحدة)
lib/seo.js              عناوين ووصف كل صفحة + خريطة الموقع
lib/booking.js          حجز الاستشارات + تنبيهك على الواتساب
lib/                    كود اللوحة والبوت
supabase/schema.sql     تجهيز قاعدة البيانات
vercel.json             توجيه الروابط
.env.example            أسماء الإعدادات المطلوبة
```

---

## ١. Supabase (مرة وحدة)
1. من [supabase.com](https://supabase.com) أنشئ **مشروع جديد** باسم `shaheen-design`.
   - المنطقة: **Frankfurt (eu-central-1)**، نفس منطقة Vercel في `vercel.json`.
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` واضغط **Run**. هذا ينشئ جدول التخزين وحاوية الصور.
3. من **Project Settings ← API Keys** انسخ:
   - **Project URL**، ويروح في `SUPABASE_URL`.
   - **Secret key** (يبدأ بـ `sb_secret_`)، ويروح في `SUPABASE_SECRET_KEY`.
   - إذا مشروعك قديم وما فيه Secret key، استخدم مفتاح `service_role`.

> المفتاح السري يعطي صلاحية كاملة على قاعدة البيانات. لا تحطه في أي ملف داخل الريبو، مكانه إعدادات Vercel فقط.

## ٢. GitHub
1. أنشئ ريبو جديد **Private** باسم `shaheen-design`.
2. ارفع كل الملفات اللي في هذا المجلد: **Add file ← Upload files** واسحبها كلها. أو بالأوامر:
```bash
git init && git add . && git commit -m "Shaheen Design"
git branch -M main
git remote add origin https://github.com/manticglow/shaheen-design.git
git push -u origin main
```

## ٣. Vercel
1. **Add New ← Project**، واختر ريبو `shaheen-design`.
   - Framework Preset: **Other**، واترك باقي الخيارات مثل ما هي.
2. قبل ما تضغط Deploy، افتح **Environment Variables** وأضف القيم اللي في `.env.example`. الضرورية:

| المتغير | قيمته |
|---|---|
| `SUPABASE_URL` | من الخطوة ١ |
| `SUPABASE_SECRET_KEY` | من الخطوة ١ |
| `ADMIN_PASSWORD` | كلمة سر اللوحة، طويلة وما تستخدمها في مكان ثاني |
| `SESSION_SECRET` | أي نص عشوائي طويل، ٣٢ حرف أو أكثر |

   متغيرات الواتساب (`WA_TOKEN` و `APP_SECRET` و `VERIFY_TOKEN` و `PHONE_NUMBER_ID` و `LEADS_KEY`) تقدر تضيفها بعدين لما تجهز Meta.
3. **Deploy**. بعدها افتح `https://مشروعك.vercel.app/admin` وسجل دخول.

> أي تعديل على المتغيرات بعد النشر يحتاج **Redeploy** من صفحة Deployments عشان يشتغل.

## ٤. الدومين
من Vercel: **Settings ← Domains**، وأضف دومينك واتبع تعليمات الـ DNS.
ما تحتاج تعدل أي رابط: العناوين وصور المعاينة وخريطة الموقع تاخذ الدومين تلقائيًا.

## ٥. ربط الواتساب
نفس خطوات Meta في القسم تحت، بس رابط الـ Webhook يصير:
```
https://دومينك/webhook
```

## التعديل اليومي (أونلاين من جوالك)

افتح `دومينك/admin` وسجّل دخول. أي تعديل تحفظه يطلع في الموقع خلال دقيقة تقريبًا.

| القسم | وش تعدّل فيه |
|---|---|
| **المتجر** | لكل منتج: الاسم، الوصف، الشارة، المدة، «وش يشمل»، وأسماء الباقات الثلاث وأسعارها ومزاياها. وتقدر تخفي منتج وترجعه |
| **المواعيد** | أيام الحجز وساعاته، والأيام اللي تقفلها لأنك مسافر أو مشغول |
| **الإعدادات** | رقم الواتساب: يتغير في الموقع والبوت مع بعض |
| **النسخ السابقة** | كل حفظ يخلي نسخة احتياطية، وتقدر ترجع لأي وحدة منها |

- أي خانة تخليها فاضية تاخذ النص الأصلي، وتشوفه باهت داخل الخانة.
- صفحات المنتجات وخريطة الموقع ونتائج قوقل تتحدث مع تعديلاتك.

**تحتاج GitHub بس** إذا بتغيّر التصميم، أو تضيف منتج جديد كليًا. هذي تتعدل في `lib/site.html`.

## حجز الاستشارة المجانية

العميل يفتح `/book` (أو يضغط «احجز استشارة» في أي مكان بالموقع)، يختار اليوم والوقت، ويكتب اسمه وجواله وموضوعه.

- **وين يروح الحجز:** يتسجل في Supabase، ويظهر في صفحة `/leads` مع الطلبات (المصدر: «حجز استشارة من الموقع»).
- **تنبيهك:** يوصلك على الواتساب بنفس طريقة تنبيهات الطلبات (القسم تحت): رسالة عادية إذا راسلت البوت آخر ٢٤ ساعة، وإلا بالقالب `new_lead_alert`. لازم يكون رقمك في `ADMINS`.
- **ما ينحجز نفس الوقت مرتين:** الوقت المحجوز يختفي من التقويم عند الكل.
- **العميل:** يقدر يضيف الموعد لتقويمه (آيفون أو قوقل) بضغطة.
- **إذا الخادم ما اشتغل:** الموقع يحوّل العميل يرسل الحجز على الواتساب برسالة جاهزة، والبوت يفهمها ويبلغك.

**تغيير الأيام والساعات:** في `lib/site.html` عدّل سطر `var BOOK={ days:[0,1,2,3,4], from:17, to:22 … }`، وحط نفس القيم في متغيرات `BOOK_*` في Vercel (الأيام: ٠ الأحد … ٦ السبت).

## قوقل والمشاركة

جاهز تلقائيًا بعد النشر:
- كل منتج له رابط مستقل (`/salla` …) بعنوان ووصف وأسعار الباقات، وبيانات منظمة (Schema) يفهمها قوقل: النشاط، جدة، أوقات العمل، الخدمات والأسعار.
- صورة معاينة لكل منتج في `og/`، تطلع لما ينرسل الرابط في الواتساب أو تويتر أو لينكدإن.

بعد ما تربط الدومين:
1. افتح [Google Search Console](https://search.google.com/search-console) وأضف الدومين (Domain property) وأكّد ملكيته بسجل DNS.
2. من **Sitemaps** أضف: `sitemap.xml`.
3. من **URL Inspection** حط رابط الصفحة الرئيسية واضغط **Request indexing**.
4. جرّب صورة المعاينة: أرسل رابط منتج لنفسك في الواتساب. إذا ظهرت صورة قديمة، أضف `?v=2` آخر الرابط.

ملف Google Business: شوف `GOOGLE-BUSINESS.md`.

## التكلفة
- **Supabase:** الخطة المجانية تكفي بزيادة لهذا الحجم. انتبه إن المشروع المجاني يتوقف مؤقتًا إذا ما انفتح أسبوع كامل، لكن البوت والموقع يفتحونه باستمرار.
- **Vercel:** خطة **Hobby المجانية للاستخدام الشخصي غير التجاري فقط** حسب شروطهم. موقع الاستوديو تجاري، فالمناسب خطة **Pro** (٢٠ دولار شهريًا). راجع صفحة الأسعار عندهم قبل القرار.

# بوت الواتساب

يرد على عملائك ويرتب طلباتهم بأسئلة قصيرة، ويحولهم لك برقم طلب. الخدمات والمواعيد والميزانيات ياخذها من لوحة التحكم.

## اختيار مهم: نفس رقمك أو رقم مستقل؟

| | نفس رقمك 0582409776 (`MODE = "coexistence"`) | رقم مستقل للبوت (`MODE = "separate"`) |
|---|---|---|
| تجربة العميل | يكلم رقم واحد، والبوت ثم أنت في نفس المحادثة | يكلم البوت على رقم، وبعدها يضغط رابط ويكمل معك على رقمك |
| كيف ترد | من تطبيق واتساب للأعمال على جوالك كالعادة، ويتوقف البوت تلقائيًا لما ترد | من رقمك الحالي، والعميل يرسل لك ملخص طلبه بضغطة |
| الإعداد | يحتاج ربط رقمك الحالي بالـ API بميزة الربط المشترك (Coexistence) | أسهل: رقم جديد ما عليه واتساب |

**أنصحك بنفس الرقم إذا قدرت تفعّل ميزة الربط المشترك.** السعودية من الدول المدعومة. لكن الربط عادة يكون عبر خطوة "Embedded Signup" بخيار ربط رقم تطبيق واتساب للأعمال الحالي، وهذا الخيار ما يظهر لكل الحسابات مباشرة.

إذا ما ظهر لك الخيار، ابدأ برقم مستقل (`separate`) وانقل لاحقًا. وانتبه: بعد الربط المشترك تتعطل بعض مزايا التطبيق، مثل الرسائل المؤقتة وقوائم البث. ورقم نُقل للـ API بالكامل ما يرجع للربط المشترك.

## خطوات تشغيل البوت

### ١. من جهة Meta
1. ادخل [developers.facebook.com](https://developers.facebook.com) وأنشئ تطبيق من نوع **Business**، وأضف له **WhatsApp**.
2. من **WhatsApp ← API Setup** خذ:
   - **Phone number ID**، ويروح في `PHONE_NUMBER_ID`.
   - أضف رقمك. إذا اخترت نفس الرقم، استخدم خيار ربط رقم تطبيق واتساب للأعمال إذا ظهر لك.
3. **التوكن الدائم:** من [business.facebook.com](https://business.facebook.com) ← Business Settings ← System Users:
   - أنشئ مستخدم نظام، وأعطه صلاحيتي `whatsapp_business_messaging` و `whatsapp_business_management`.
   - ولّد له توكن، وهذا هو `WA_TOKEN`.
   - لا تستخدم التوكن المؤقت اللي مدته ٢٤ ساعة.
4. من **App settings ← Basic** انسخ **App Secret**، وهذا هو `APP_SECRET`.

### ٢. من جهة Vercel
أضف في **Settings ← Environment Variables**:
- `WA_TOKEN` و `APP_SECRET` و `PHONE_NUMBER_ID`: من الخطوة ١.
- `VERIFY_TOKEN`: اخترع كلمة سر طويلة، تستخدمها في الخطوة ٣.
- `LEADS_KEY`: كلمة سر لصفحة الطلبات. ما تحتاجها إذا مسجل دخول في اللوحة.
- `MODE`: `coexistence` إذا البوت على نفس رقمك، أو `separate` إذا له رقم مستقل.
- `ADMINS`: رقم جوالك الشخصي بصيغة 9665XXXXXXXX.

وبعدها **Redeploy**.

### ٣. اربط Meta بالبوت
من **WhatsApp ← Configuration ← Webhook**:
- **Callback URL:** `https://دومينك/webhook`
- **Verify token:** نفس `VERIFY_TOKEN`
- **اشترك في الحقول:** `messages`. وإذا كنت على نفس الرقم، اشترك كمان في `smb_message_echoes`، وهو اللي يخلي البوت يوقف لما ترد أنت من التطبيق.

### ٤. جرّب
من جوال ثاني، أرسل "هلا" لرقم البوت.

## إدارة البوت من جوالك

أرسل هذي الأوامر لرقم البوت من الرقم اللي كتبته في `ADMINS`:

| الأمر | وش يسوي |
|---|---|
| `#طلبات` | آخر ٥ طلبات |
| `#وقف 9665XXXXXXXX` | يوقف البوت عن عميل وتكمل معه أنت |
| `#شغل 9665XXXXXXXX` | يرجّع البوت لعميل |
| أي رسالة ثانية | تعرض لك الأوامر |

**صفحة كل الطلبات:**
```
https://دومينك/leads (أو بالمفتاح: ?key=LEADS_KEY)
```
تقدر تحفظها في المفضلة. ولو تبي البيانات بصيغة JSON، أضف `&format=json` لآخر الرابط.

## تنبيهات الطلبات الجديدة

يبلغك البوت بكل طلب جديد بطريقتين:
1. **مجانًا:** إذا راسلت رقم البوت من رقمك في `ADMINS` خلال آخر ٢٤ ساعة، يرسل لك ملخص كل طلب جديد كرسالة عادية. يكفي ترسل له أي كلمة كل يوم.
2. **بقالب معتمد (مدفوع، لكل رسالة):**
   - أنشئ في Meta قالب من فئة **Utility** باسم `new_lead_alert` ولغته العربية، ونصه:
     > طلب جديد من {{1}}: {{2}}. رقم الطلب {{3}}، ورقم العميل {{4}}.
   - بعد ما يعتمدونه، اكتب اسمه في `OWNER_ALERT_TEMPLATE`.

إذا كنت على نفس الرقم، المحادثة كلها تظهر لك أصلًا في تطبيق واتساب للأعمال.

## ملاحظات

- **أمان البوت:** يرفض أي طلب ما يحمل توقيع Meta الصحيح (`X-Hub-Signature-256`)، فما أحد يقدر يرسل له رسائل مزورة.
- **إيقاف البوت لما ترد بنفسك:** هذا يعتمد على إشعار `smb_message_echoes`. إذا رديت من التطبيق ولاحظت إن البوت ما توقف، استخدم أمر `#وقف` وبلغني نعدله على شكل البيانات الفعلي.
